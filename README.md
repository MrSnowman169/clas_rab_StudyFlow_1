# StudyFlow — Python + Flask

## Запуск (Windows / macOS / Linux)
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
Відкрийте http://127.0.0.1:5000

Завдання та налаштування зберігаються локально у `study_data.json`.

MVP: завдання CRUD, виконані/невиконані, автоматичний підбір за порядком, два таймери, pause/resume/stop, результат, базові нагадування.

Списки завдань: створюйте списки (наприклад, «Понеділок» або через швидкі кнопки днів тижня), призначайте їх завданням і розгортайте список, щоб побачити його завдання. Усередині списку є кнопка «＋ Додати завдання» (додає завдання одразу в цей список) і кнопка «Використати», яка копіює завдання списку у верхній блок «Мої завдання» без дублікатів; сам список залишається як шаблон. Фокус-сесія бере лише завдання з верхнього блоку, тому шаблонні завдання не дублюються. Сортування завдань — за алфавітом або за тривалістю (менші/більші спочатку); вибір зберігається та застосовується і до порядку завдань у фокус-сесії.

Дії зі списками та завданнями виконуються без перезавантаження сторінки (AJAX): оновлюється лише потрібний блок, тож анімація запуску сайту не програється повторно.

Налаштування відкриваються кнопкою «⚙ Налаштування» у шапці. Там же можна створювати нагадування на конкретну дату й час — вони зберігаються у `study_data.json` (поле `reminders`) і не зникають після вимкнення програми. Коли час нагадування настає, з'являється спливаюче повідомлення (і сигнал, якщо увімкнено звук).

Прототипні обмеження: активна сесія не зберігається після перезавантаження сторінки; «Продовжити» після таймера задачі додає 5 хвилин; звук — короткий сигнал браузера, системні notifications доступні за дозволом браузера.
